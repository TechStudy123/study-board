# 社内勉強会の案内サイト

社内勉強会の予定（`data/events.json`）を、日付の順に一覧で表示する静的なサイトです。
GitHub Pages で公開します。

## ファイル
- `index.html` … 案内のページ
- `data/events.json` … 勉強会の予定のデータ
- `tests/test_events.py` … 予定のデータを確かめる自動テスト（CI で動きます）

## 完成の定義
- [ ] 受け入れ条件をすべて満たしている
- [ ] 自動で動くテスト（CI）が通っている
- [ ] プルリクエストでレビューを受けてから main に取り込んだ
- [ ] 公開されたページで実際に確かめた
